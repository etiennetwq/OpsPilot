# 两个独立项目的简历表述

## OpsPilot — 日志证据驱动故障调查 Agent | Python / FastAPI / SQLite / Hybrid RAG

基于 Loghub 固定版本 Apache 真实公开日志构建独立故障调查系统，完成 2,000 行解析、脱敏与行号溯源；实现 BM25 + 本地 LSA 向量 RRF 融合检索、可选重排及只读日志查询/上下文/统计工具，提供 FastAPI 与网页演示、带日志及文档引用的回答、OpenAI 兼容 API 接口和离线替代流程。设计基于上游六类事件模板的 15 题证据检索/拒答评测，离线 Hybrid 日志 Hit@5 为 75%、证据任务成功 12/15；完成 23 项自动化测试。指标限于小样本事件证据任务，未测真实 LLM 质量，不代表生产根因准确率。

## LLM Security Audit Gateway — LLM 安全审计项目（沿用原独立仓库）

基于 Python、FastAPI、SQLite 与 DeepSeek API 构建 LLM 请求安全审计网关，实现 API Key 鉴权、按用户限流、基于规则的 Prompt 风险扫描与阻止、结构化安全告警和会话审计；提供管理员过滤查询，并通过 Pandas 分析审计记录、Streamlit 展示聚合趋势与异常复核线索，配置 pytest 测试覆盖鉴权、限流、日志与错误响应。项目聚焦 LLM 应用安全控制，与 OpsPilot 的真实公开日志处理、Hybrid RAG 及只读诊断工具编排互补。
